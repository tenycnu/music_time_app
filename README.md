# Music Time - Konser Bileti Satın Alma Uygulaması

## Açıklama
Bu proje, Mobil Uygulama Geliştirme dersi haftalık eğitimi bitirme projesi envanteri kapsamında geliştirilmiştir. Geliştirilen bu katalog uygulamasında kullanıcılar; güncel konserleri listeleyebilir (GridView), sanatçı detaylarına erişebilir (Route Arguments & Navigator) ve favori ekleme (State Güncellemesi) işlemlerini gerçekleştirebilir. Uygulama arayüzü Figma UI/UX tasarımına (Pembe Konsept) birebir sadık kalınarak tasarlanmıştır.

## Kullanılan Flutter Sürümü
* Flutter Web (DartPad Environment) / Flutter 3.x

## Proje Klasör Yapısı
* `lib/models/` -> Konser veri modeli şablonu
* `lib/screens/` -> Ürün listeleme (GridView) ve Detay Ekranları
* `lib/main.dart` -> Rota (Route) tanımları ve uygulama giriş noktası

## Çalıştırma Adımları
1. Bu projedeki `lib/main.dart` kaynak kodunu kopyalayın.
2. [dartpad.dev](https://dartpad.dev) adresini tarayıcınızda açın.
3. Sol üstten `Create > Flutter snippet` oluşturup mevcut kodları silin ve kopyaladığınız kodu yapıştırın.
4. Sağ üstteki mavi `Run` butonuna basarak uygulamayı tarayıcı üzerinden canlı olarak test edin.
